# Phase 4A: Simulation + Rendering Integration

## Overview
Phase 4A integrates the `SimulationController` into the `main3D.cpp` rendering loop, enabling real-time animated pipe bending simulation with interactive controls.

## Key Components

### SimulationController
- **Role**: Orchestrates simulation (state machine, operation execution, geometry updates)
- **Location**: `Core/SimulationController.h` / `.cpp`
- **Key Methods**:
  - `loadProgram(ops)` - Load operations
  - `play()` - Start simulation
  - `pause()` - Pause simulation
  - `reset()` - Reset to start
  - `update(deltaTime)` - Update per frame
  - `getPipeGeometry()` - Get generated 3D geometry

### main3D.cpp (Phase 4A)
- **Role**: Rendering loop + input handling
- **Location**: `App/main3D.cpp`
- **Features**:
  - Frame timing with deltaTime calculation
  - Keyboard input processing
  - Real-time geometry/mesh generation
  - HUD display (console-based)
  - OpenGL rendering with shaders

### TubeMesh
- **Role**: Converts centerline to 3D tube surface
- **Updates**: Each frame based on current geometry
- **Output**: Vertices (position + normal) and indices for GPU
